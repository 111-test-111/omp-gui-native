# 聊天、审批与原生任务

使用前单独安装 OMP 并完成原生登录。设置中的 Providers 配置 OMP 本身及其模型提供商；Models 按原生提供商分组。模型角色、认证和 worker 行为由 OMP 决定，具体配置范围见[原生接入](OMP_INTEGRATION.md)。

Models 默认让全部原生模型出现在输入框底部的模型选择器中。可见模型的按钮显示睁眼，点击隐藏后显示闭眼，不额外显示「已隐藏」文字；隐藏的行仍留在设置中，点击闭眼可重新启用。当前会话使用的模型也不会被额外补回选择器，隐藏不会切换或停止已有会话。每个提供商的「隐藏全部／启用全部」作用于该组当前完整目录，包括搜索和版本折叠没有显示的条目，不影响其他提供商；后续新发现的模型默认显示。全部隐藏时选择器显示恢复提示，不回退到全部模型。Hydra 组合独立维护，隐藏单个模型不会修改组合。

旧「你的模型」添加列表和 15 个上限不再生效；首次使用新规则时默认显示全部模型，已有模型参数偏好保留。每行参数按钮继续设置新对话的模型默认参数。隐藏状态保存在当前 GUI edition 的偏好中，不修改 OMP 的模型、账号或角色配置。

点击模型名称区域，在该行旁打开只读详情：声明的输入类型、上下文窗口、最大输出，以及输入、输出、缓存读取和缓存写入的美元／百万 token 基础单价。弹窗宽 400 点，高度随内容收紧；正文超过 340 点时滚动，标题和关闭按钮保持可见。详情复用已读取的 OMP 目录，不启动会话或发送模型请求；参数和隐藏按钮各自独立。免费、套餐内含、价格浮动和价格未知分别标注，全零价格不推断为免费，缺失的上限和单项价格显示未知。小额缓存单价保留有效数字，实际计费与费率解析仍由 OMP 负责。关闭详情不修改任何配置。

## 聊天模型选择与套餐用量

输入框的模型按钮第一次点击仍打开原有思考强度面板，第二层使用 510 × 439 pt 模型列表：视口正好容纳五个完整模型行，末行底框下方留出约 14 pt 空隙，服务商标题与首个模型行的间距约等于相邻模型行文本的间距，顶部搜索框延伸到右侧内容边界。打开前按较大页面的尺寸选择可容纳的弹出方向，两层沿用同一按钮锚点；屏幕边缘的最终避让仍由系统决定。切换时只让模型页轻微淡入／横移，退出的思考页立即移除，避免 Canvas／玻璃色条随退出动画残留；减少动态效果或性能模式下直接切换。左侧按 OMP 可用目录列出已配置的原生服务商，只显示紧凑图标，悬停或辅助功能读取其名称；右侧只显示服务商名称及未隐藏的模型，不显示或读取账户用量。模型行包含名称、原生 selector 和当前选择标记；搜索匹配当前服务商内的名称、selector 和服务商 ID。Hydra 开启且有配对时，左列另有带名称提示的组合图标。选择仍交给 OMP，服务商图标不代表其他运行时。

账户套餐与余额统一放在“设置 → 服务商 → 已配置”。列表包含已登录服务商、OMP 可用目录中的 API Key／免密服务商及已确认的额度账户；API Key 行提供就地编辑入口。登录配置的行不再显示“已登录”标记，重新登录／退出按钮与额度信息本身说明状态。每行只保留关键额度数值和有效的未来重置／滚动补充时间，或可用余额。移除重复标题、进度条、更新时间及赠金／充值明细，多账户时保留原生返回的账户标签；用量刷新复用页面顶部按钮。

模型当前选择只显示勾号，不加底色或边框。ChatGPT Codex 使用 OpenAI 结形标记，OpenRouter 使用大写 O；其他未匹配专属图标的服务商也使用大写首字母，字号适当放大而标记框不变。名称在模型、服务商、密钥编辑及图片后端间共用核对结果；`minimax-cn` 显示“MiniMax（中国）”，搜索既接受这个名称也接受原生 ID。密钥编辑补齐只有模型目录、没有登录策略的原生服务商，并按精确 ID 分别保存中国站与国际站密钥。服务商设置按 OMP 明确声明的共享凭据归属合并已配置行；Codex 浏览器与设备码是同一服务商的两种登录入口，指向相同的原生凭据来源，不重复展示。登录入口数量不代表实际账号／凭据条数。没有原生归属证据的来源保持独立，多账户用量仍分别保留。

套餐用量来自公开 `omp usage --json`，与设置 → 用量中的本地轮次统计不同。只显示有有效来源时间的原生数值；缺失、不支持、未知状态、明确估算、超过十分钟或已越过窗口重置时间的项全部隐藏，不补零、占位条或猜测套餐。原生明确返回的零值和超额百分比保留，不根据模型价格估算额度。仅可见服务商设置持有共享读取与短时内存缓存；进入或刷新时核对 OMP 活动 profile，目录或 profile 改变后丢弃旧账户结果，离开最后一个设置视图时取消读取。隐藏后没有后台轮询，不启动聊天或发送模型请求。暂未增加收藏，详见[原生边界](OMP_INTEGRATION.md#subscription-usage-and-voice-boundaries)。

DeepSeek 官方直连可在已配置行显示可用总余额，保留 CNY／USD 和原始十进制精度，不换算为套餐百分比，也不以赠金或充值额推断总余额。当前 npm SDK＋Bun 路径沿用 OMP 的模型配置／存储／环境密钥优先级；其他安装的扩展路径只使用 OMP 用量命令实际提供的凭据。配置为第三方中转、缺少原生接口或读取失败时不显示余额。两处服务商界面共用离线 logo；模型列表只允许纵向滚动，长名称和 selector 在面板宽度内截断。滚动锁尊重原生视口在内容较短或弹窗变宽时的居中位置，忽略自身修正产生的同步重入通知。

进入模型页会等待登录 shell 环境发现，再主动读取 OMP 模型目录，与已在进行的读取合并。首次进入时显示加载状态；启动流程尚未完成也无需等待其他后台初始化。读取失败仍显示原始错误并提供重试。

## 本地听写

先在设置 → 听写选择语言、安装 Apple 语言资源并允许麦克风访问；已拒绝权限时，页内按钮打开系统麦克风设置。资源由 macOS 26 管理，首次安装需要网络，之后在本机识别，不需要额外命令行工具、账号或 API Key。已安装的语言可重新安装，重新请求并校验系统资源；系统已保留资源时立即就绪。切换语言沿用已验证的资源状态，不闪现安装提示。不支持的设备或语言会明确提示，不自动改用英语。打开设置不会自动下载或申请权限。

输入框底部的麦克风把语音转写到当前草稿，支持主会话和辅助编辑器。准备完成后点击直接开始录音，不弹出配置窗口或显示语言资源检查行；条件不足时只显示前往听写设置的提示。再次点击麦克风或「停止录音」结束并转写，每段最长五分钟。录音和转写期间可编辑草稿，所有发送／排队路线暂时禁用；文字只追加到原草稿，保留附件、引用和命令，需自行检查并发送。若草稿已被另一条输入替换，转写文字保留在可复制的恢复区，不写入新草稿。

一次只能有一个编辑器听写或安装资源。「取消」、切换会话／设置或关闭编辑器会取消操作并清理临时录音；迟到结果不会改变草稿。语言资源由系统共享管理，GUI 清理不删除它们；语言选择保存在当前 edition 的偏好。麦克风拒绝时按页内说明到系统设置重新授权；安装／识别失败保留草稿，可重试。转写正文最多 128 KiB。

## 独立任务、侧栏与归档

设置现在位于主窗口，侧栏的设置、应用菜单和设置快捷键使用同一入口。设置侧栏的「返回」、Escape 或 Command-W 回到聊天；再次打开保留所选设置页。底下的会话和草稿保持挂载，文件预览保留页签、选择和可见性偏好，覆盖期间暂停读取与聊天的可见更新；返回后继续原阅读位置。聊天菜单和快捷键在设置覆盖时不操作隐藏会话。

无需先添加项目：欢迎页的「新建任务」、侧栏「任务」旁的 + 和普通新对话入口均可创建独立任务。项目与任务是明确的不同归属；每个任务按会话 UUID 使用当前 edition 的 `tasks/<UUID>/workspace/`，实际发送或首次启动原生连接（含记忆读取）前准备目录，查询和选择不会创建。OMP 的会话、上下文、记忆及 host tools 使用同一解析目录；缺失项目记录不会回退成任务。文件、worker 隔离与结果应用仍由 OMP 负责。

第一条消息提交前，可从欢迎文案切换项目或独立任务；开始发送的边界先持久化，已有消息、正在加载／维护或已有 worktree 的会话不能借此换目录。显式从项目新建优先于通用位置偏好。转发独立任务会生成新的任务工作目录，不共享源任务的执行目录。

侧栏常态分为「项目」和「任务」，点击分区头的箭头、标题或留白均可折叠／展开并记住状态；箭头与文字间距固定。悬浮分区头时，右侧显示与项目文件夹行相同的无底框加号；项目加号添加目录或克隆，任务加号新建独立任务，两者不会触发分区折叠。项目添加菜单打开时保留加号锚点，移开指针也不会撤下菜单。拖动项目文件夹可调整顺序，拖动期间临时收起各文件夹，结束后恢复各自状态。任务按待处理、置顶、最近活动和 Settle 排序，支持同组拖动；键盘导航使用相同顺序，并跳过折叠的 Settle 任务。项目计数只统计顶层可见会话，不把 Hydra head 加进去。项目右键菜单可编辑图标；图标选择器提供分类 emoji 及中英文关键词搜索。保留当前等待 badge、Hydra 卡片及 Settle 行为。

每个展开的项目默认显示最多 5 个主会话；helper/head 随父会话显示，不另占名额。「显示更多」是淡灰纯文本操作，与上方会话标题左对齐，不带图标或底框；每次增加最多 5 个，显示完后消失。折叠项目再展开会重置为 5 个，其他项目的页数独立；拖动项目时的临时收起不重置页数。已折叠的 Settle 会话不占显示名额；展开 Settle 后与普通会话共用名额。键盘导航和拖动只使用当前可见的会话，搜索与命令面板仍能找到全部记录。

顶部铃铛切换「活动视图」，汇总所有项目与独立任务，依次显示待处理、置顶、Today／Yesterday／更早日期和 Settle 分组，不受项目分页或项目／任务分区折叠影响。行内显示项目名或「任务」，保留时间和父会话下的 helper/head；再点一次回到项目与任务。沿用原活动视图的快捷键和偏好身份。

设置 → 归档提供搜索、会话类型及项目筛选，并按项目分组。批量删除在打开确认时固定所选归档 ID，确认后只删除该集合中仍在归档的记录，不连带删除未命中筛选的子会话；筛选或记录在确认期间变化不会扩大范围。单条删除保留原有语义。删除任务历史不删除其工作目录中的文件。

## 新对话默认值与选区操作

空白主会话把原生输入框放在聊天区域中部，项目／独立任务切换入口位于其上方；短窗口先隐藏应用图标，再让出引导文案的空间。首条输入进入时间线后，同一个编辑器平滑停靠到底部，草稿、输入法、附件、命令补全和 OMP 扩展附件保持原有归属。加载中的历史、交接会话和原生子代理不使用这个空白布局。切换聊天直接落到各自布局；性能模式或减少动态效果时直接到达最终位置。

新对话默认沿用当前聊天的模型与推理强度；没有当前聊天时，使用最近记录的 OMP 模型及其参数偏好。设置不再提供固定模型或固定推理强度入口，旧的固定模型偏好在加载时移除。项目的 Hydra 预设仍优先。设置 → 通用 → 新对话中的位置选项可沿用最近项目／任务，或总是创建独立任务；显式项目新建与明确 worktree 操作保留项目优先级。

消息菜单中的「复制」优先使用属于当前消息的选区，否则复制全文；「将消息复制为 Markdown」始终复制原始全文。「添加到回复」固定菜单打开时的选中文字，没有有效选区才引用全文；同一消息的不同片段可分别引用，重复片段不会再次加入。输入框或其他消息的选区不会被借用，读取引用不修改剪贴板。原生行内代码和公式继续经已有导出映射还原原文。

## 聊天时间线与过程折叠

同一轮中相邻且内容相同的错误和重试警告只显示一条红色错误行，红黄两次报告算作同一次失败。连续再次发生时，在原行右侧累计显示次数（例如 `×3`），不限制于某个模型服务商或错误类型。独立警告继续使用黄色；不同错误、新消息或其他内容、以及轮次边界会分开错误组。最终失败状态重复报告已出现的错误时不额外计数。已有聊天与分页历史也使用相同规则，保存后保留累计次数。

子代理完成卡片按原生派出工具的身份保留在所属轮次，即使整批都完成、子代理已归档或父轮次已经折叠，报告入口仍可见；展开过程不会重复显示完成卡片。缺少旧工具身份的记录按开始时间归属，完成较晚不会把卡片挪到后续轮次。连续成功的完成卡片保留合并，失败和停止保持独立。多份报告采用固定页头、普通报告卡片及有界滚动；点击卡片展开相应报告，不再使用菜单切换单份报告。文件应用结果仍以 OMP 原生事实为准。

运行中的轮次按事件到达顺序从上至下显示。阶段性模型文本正常显示；只有相邻的工具调用、思考和普通信息/系统通知合并为步骤组，复用现有工作状态栏。文本、Hydra 派遣卡片、计划、警告和错误会分开前后的步骤组，并留在各自到达的位置。思考是否可见仍由外观设置控制；todo 快照仍只投影到顶部进度入口。

每个步骤组使用摘要、文字右侧的展开箭头和细线连接的树状步骤，多个步骤时显示数量；折叠头不留前置图标缩进，与正文左缘对齐。正在工作的最后一组默认展开，阶段结束后自动收起；用户手动打开／关闭的选择按组保留。展开后显示全部步骤，没有「显示更多」或早期步骤分页。已有内容的步骤组标题不显示耗时；整轮末尾单独显示工作短语及累计耗时，保留设置中的卡片／单行选择。轮次结束后，总耗时显示在总折叠头上。组内工具、思考和信息通知沿同一树状列排版，工具原生身份及详情交互不变。工具行及展开 diff 的文件头不再附带侧栏打开按钮，文件预览入口保留在右键菜单。系统通知展开后按原文以等宽纯文本显示，不做语法高亮，保留选择复制与有界滚动。思考过程使用与工具相同的单行图标／文字／箭头布局，行内预览原始思考正文的第一行，长内容截断并优先保留右侧箭头。每条思考的正文默认折叠，流式更新不会自动展开；逐条记住用户选择，折叠步骤组或离屏后恢复。展开后思考正文最多占 360 pt 高度，超过时在行内滚动；流式期间打开或重新打开时立即定位到最新内容，并在内容增长时继续跟随。主动向上滚动可阅读已有内容，回到底部后恢复跟随；布局测量不会误判为用户滚动。工具详情继续使用各自行内的有界滚动区域；长会话保留原有按需挂载。

工具详情的参数、普通输出与 diff 正文使用同一套随主题变化的灰色文字；共享 diff 视图与原始补丁回退均使用该基础颜色，增删标记和底色继续区分变更。读取源码时，未高亮的文字也使用该颜色，语法标记沿用现有配色。

编辑与写入工具完成后使用各自原生结果中的文件路径，多个路径按出现顺序去重并列，保持相同的单行展示。编辑显示「正在编辑／已编辑」，原生文件写入显示「正在写入／已写入」，步骤组摘要也分别列出编辑和写入；通过 `write xd://…` 调用其他工具时仍使用实际工具的状态文案。

轮次结束后，阶段性文本、步骤组、Hydra 卡片和子代理/后台等待一起收进一个默认折叠的过程区。总折叠头从正文左缘开始，依次显示现有 OMP logo、总耗时／结束状态及展开箭头，底部保留分隔线，与普通步骤组区分；正文保留最终回复。文件变更条独立显示在最终回复下方，不随过程区折叠，保留文件列表、恢复和 diff 入口，去掉开头的加减图标。展开过程后恢复相同的时间顺序，最终回复不重复。失败或中断的轮次显示相应结束状态，不把中间说明冒充最终回复；诊断保留在过程中。开头的用户输入保留在过程区外，后续追加输入留在原位置。

待处理的问答 badge 仍在时间线末尾，审批 badge 仍在输入框上方；它们独立于过程折叠，保持可操作，回答/决策表单沿用原有 popover、草稿和原生请求身份保护。时限/用量提示不作为普通信息折进步骤组。

文件归属来自当前会话的工具修改记录。会话目录、侧栏项目及 Git 确认属于当前仓库的 worktree 中，只有本会话明确记录过的编辑才进入文件变更条、输入框统计和 diff；不扫描其他 worktree 的改动，也不计入项目外的记忆、设置或临时文件。worktree 文件保留原始路径与工具补丁，提交并合入主目录后仍可查看；外部 worktree 路径不进入当前 checkout 的恢复或合并文件列表。

命令快照同时保存当时的 `HEAD` 树；其他任务在命令运行期间合入当前分支时，先将旧快照中的本地内容对齐到新提交，再计算命令留下的修改，因此合入的新增、删除、改名和代码行不会算到该命令。跨 `HEAD` 变化的轮次卡片、输入框统计和 diff 使用工具各自的补丁，保留本会话对同一文件的实际写入。快照遇到 Git 索引锁、捕获期间 `HEAD` 变化或无法干净对齐时，不从整个工作区推定命令归属；明确的原生编辑记录仍保留。新记录保存这些边界，重开会话继续使用。

打开已有会话时，可见的旧轮次卡片按已保存的工具记录重新计算文件与增删行汇总，包括旧版本误存为零文件的结果；计算后保存版本标记，后续打开直接复用。输入框统计等待历史加载完成后计算，与 diff 使用相同的文件来源。历史记录中没有保存的编辑不能从其他任务的提交或整个工作区反推。

## 输入、投递与草稿

| 操作 | 原生语义 |
| --- | --- |
| 空闲时发送 | `prompt`启动一轮 |
| 补充当前任务 | steering，交付时机由 OMP 决定 |
| 当前任务后执行 | follow-up，进入 OMP 原生队列 |
| 停止并发送 | 先请求原生中断，再提交新输入 |

输入接收、被原生消费、单轮回复结束及后台工作全部结束分别显示/处理。普通空闲发送不必显示投递 tab；已有工作后的排队消息显示投递记录。原生确认接收后，只清除仍与已提交内容一致的草稿，之后编辑的新内容保留。

失败和送达未知均保留可恢复输入。未知不等于未送达，不能自动重发或按 Return 复制提交。检查当前投递状态、原生回复或明确错误后处理，不因界面暂时空闲而推定原生任务结束。

在支持 SDK 队列桥的安装中，队列提供撤回及移除。只有 OMP 确认移除了确切消息，GUI 才删除记录或把文字/附件合并回当前草稿。已经消费的消息不能本地伪造撤回；standalone 或握手未通过时控件不可用。GUI 不另建执行调度器。

## 审批和问答

原生请求在当前会话的输入区域以 badge 提示。点击琥珀色审批 badge 打开决策 popover；紫色问答 badge 打开问题表单。背景会话在侧栏显示「等待批准」或「等待回答」，进入源会话处理。查看会话本身不会回复请求。

工具审批展示原生工具名、来源/原因、命令或文件内容，底部是「拒绝」「允许」两个紧凑操作。信息区有界滚动，决定点击后关闭 popover，回复在后台写入。多个待审批请求聚合为同一个 badge，popover 内逐条翻页切换；翻页只改变展示，不提前回复任何请求。底部的「全部拒绝」「全部允许」逐条回复当前每个请求，各用各的单次拒绝/允许选项，绝不升级为会话级授权。⌘Return 归当前可见页的批准操作。

普通 `confirm`保留原生布尔值；匹配 OMP 原生工具审批 select 的标题及已知选项时保留单次允许的 `Approve` / `Approve Once` 和拒绝的 `Deny` 原始字符串。原生可同时提供会话、文件或目录的记忆授权；GUI 仍只展示单次允许与拒绝，不记录更广授权。特别是缓存授权菜单中的 `Approve` 本身可能表示目标授权，不能替代 `Approve Once`。未知、重复、格式损坏或缺少单次允许的选项保留为原生普通选择题，不猜测权限含义。

问答支持原生选择、自由输入、多选及多页请求。每页高度按实际内容计算，翻页保持 popover 锚点与底部位置，多于三个选项时滚动选项区；按原生题目决定是否允许补充、跳过、secret 或多行输入。题目文本属于用户/OMP 数据，不作为翻译键。新版原生 `ask` 没有独立的 skip/note 字段，跳过会提交明确的「用户未回答」文本，不选择任何选项，也不取消任务；旧版 SDK 表单仍使用空输入加未回答说明。

草稿绑定请求实例、原生会话和进程 generation。切换聊天、关闭并重开表单可继续当前活跃输入；双窗口共享同一请求状态。确认 transport 写入后才清已提交输入，该写入没有逐条原生接收 ACK。未知送达不自动重发；取消、超时、退出或释放撤下请求，旧表单只读。没有跨会话收件箱、最近请求档案或磁盘请求草稿。状态细节见[侧栏提醒](thread-reminders.md)。

## 旁问

主聊天输入框底部、上传按钮右侧的「旁问」按钮使用 `plus.message` 图标，打开原生弹出面板，询问当前工作的说明；主会话可以继续回复或执行工具。旁问由 OMP 的 `btw` 独立处理，不能调用工具，不进入 steering/follow-up、主时间线、Hydra 或 GUI 待办。首用时可以发出一次真实请求；当前进程明确不支持时保留问题并提示升级后重启应用，不探测或自动更新 OMP。

面板在弹出前测定完整尺寸，从按钮上方展开；打开期间保持固定视口，答案增长或输入框增高只调整内部布局与滚动，不重新展示窗口。

当前连接同时只运行一个旁问。答案完成后可在同一原生主题追问，或另开新主题；取消只针对旁问。输入最多 128 KiB，超限拒绝提交；一个主题最多追加到 16 轮或累计原生问答正文 1 MiB，达到任一边界后需新主题。GUI 合计显示正文最多 64 KiB，先省略较早片段并提示；原生记录不由 GUI 删除或重写。

旁问草稿与主输入分开，应用本次运行期间由所属会话的多个窗口共享。关闭弹出面板释放正文渲染和布局资源，不取消仍运行的旁问；重开使用当前有界状态，不读取完整历史。匹配的原生接收确认只清未被后续编辑的旁问草稿；超时、缺失终态和帧错误保留未知，不自动再问。切换原生会话、分支或进程退出后，不自动恢复提问或全量读取 sidecar。

回答终态先于原生 sidecar 落盘，协议没有保存成功 ACK。GUI 不将「答案完成」标为「已保存」；保存失败显示在旁问内，不混入主回复。后台连接自动回收时，先关闭 stdin，让 OMP 排空保存与输出并真实退出；期间拒绝新输入，不设自动强杀时限，也不因回到该聊天而重开进程重发。已知保存失败时保留连接，不开始自动回收；更换运行连接前需解决原生存储错误。显式停止/退出仍沿用原来的终止语义。

首版仅展示当前连接中本次打开的主题，没有主题历史浏览或跨连接恢复；费用仅以 OMP 原生会话统计为准，不重复估算或累加旁问费用。

## 历史编辑与上下文

已发送消息的编辑入口使用原生 `branch`并恢复该用户输入及附件。分支成功后采用 OMP 返回的会话身份；原生扩展拒绝分支时保留原会话。恢复项目文件是另一项操作，沿用差异预览和冲突保护；会话分支成功不等于文件恢复成功。

消息编辑面板保留原有紧凑表单和文件回退开关，在弹出前测量内容，从铅笔按钮处展开；文字、附件和其他元素变化时按实际高度增减，上限为 800 点，并受屏幕可用高度限制。未到上限时不预留空白、不显示外层滚动条；文字输入区先使用标题、附件和操作按钮以外的可用高度，容纳不下时才使用原生自动隐藏滚动条。其他内容超过整窗上限时才启用外层滚动。高度变化时重新对齐原按钮，不重播弹出动画。回退开关默认关闭，之后又被修改的文件仍按冲突保护保留。

当前文件回退只使用轮次保存的当前执行目录 `touchedPaths`。聊天的文件统计和差异还可以显示同仓其他 worktree 的工具编辑，因此「已编辑文件」不等于现有检查点回退列表：在独立任务 worktree 中编辑后 fast-forward 合入当前目录，仍可能因 `touchedPaths` 为空而没有文件回退开关。前后检查点有差异也不会自动补足这份归属记录。此处是回退归属未覆盖该流程的限制；不能直接使用整个检查点差异替代，否则会混入同期其他任务的改动。

普通 OMP 会话的上下文圆环不再依赖已上报的用量；应用刚打开、尚未激活或已回收连接的会话也能打开 Usage。最近的原生上下文、统计及已确认结果随 GUI 会话保存，打开时先显示快照，并注明它来自保存的数据；连接回收不会清空这些只读内容，也不会保留旧连接的压缩中、待确认命令或超时状态。缓存只用于同一原生会话文件。已有会话进入可见聊天列后及原生工作结束时自动预取，面板复用原生上下文未变化时已完成的读取；手动刷新始终重新读取。没有缓存的旧会话首次仍需获取原生数据，新建空会话不会仅因预取而启动 OMP。预取、打开上下文区域或点击刷新按需建立或恢复只读连接，不提交草稿或创建聊天轮次；并发读取共用冷启动和原生统计请求。原会话丢失时报告错误，不自动换成空会话。历史原生 worker 不会因此被重新启动。

原生子代理的圆环与 Usage 使用只读路径：运行中读取 OMP 进度的 `contextTokens` / `contextWindow`，完成后从所选 worker 的有界日志恢复最近一次响应的用量，缺失窗口上限时只查询该 worker 模型的已加载原生目录。累计 `tokens` 消耗不作为上下文占用，主代理的窗口也不作为子代理上限。刷新只读日志，不建立进程、不重放时间线、不提交草稿。数值反映最近一次已上报的响应，可能不包含后续待处理消息或工具结果；压缩后没有新用量时显示未知。子代理面板保留刷新、占用与缓存命中率，不显示普通会话的压缩、交接、导出或原生统计控件，这些动作由 OMP 管理。

普通会话 Usage 的上下文区域提供原生统计、自动压缩开关、自定义压缩说明、handoff 和 HTML 导出。说明输入框下方直接排列操作按钮。修改操作仍要求会话真正可安全管理；等待原生确认期间不重复提交，也不把短时刷新排到串行维护命令后面。普通模型工作期间已有连接仍能只读刷新：弹窗在打开前测定高度，展开或收起分区后按内容自适应高度，超过上限时滚动；保留已有内容，并依次发布已就绪的上下文占用、统计及交接正文，不因较慢的统计或历史读取推迟前面的数据；只停用刷新按钮自身，不切换其他控件的可用外观或重排窗口。切换会话时重建面板的本地状态；统计缺项为未知。

压缩过程中仅显示进行中状态，不显示进度百分比说明。完成后以单行显示「上下文压缩已完成：压缩前 xxx token → 压缩后 xxx token」；压缩前数量来自原生压缩结果，压缩后数量固定为完成后首次读到的原生上下文用量，不随后续聊天增长而改变。原生未提供的数值显示「未知」，不估算或沿用压缩前用量。

「创建交接」由 OMP 生成交接正文并提交到当前会话的压缩记录，通常不会创建独立 Markdown 文件。成功后显示「交接已完成，内容已保存在本会话中」，可展开「交接内容」、复制或通过「另存交接…」导出 Markdown。重开面板、恢复连接及迟到确认都从当前原生历史分支恢复正文，不再次生成；OMP 返回独立文件路径时才显示该路径和访达入口。明确失败或空结果不能被旧交接正文替换为成功，上下文占用下降本身也不是成功依据。

正常聊天记录与内联工具详情保留。[会话记录侧栏](file-preview.md)提供当前原生分支及已知子代理的分页记录、筛选、工具详情和全屏分栏。当前没有任意历史树导航、独立 fork、工具/MCP 检查面板或运行时诊断页。窄布局将聊天动作收进「对话操作」。

## Fast 模式

支持 Fast 的模型在模型选择/思考强度弹出面板左上角显示闪电开关，位置与右上角重置按钮对称，两枚按钮共用圆形液态玻璃样式。能力读取 OMP 的公开模型 API、identity 和 service tier 元数据；模型名称和兼容端点本身不作为支持依据。目录发现只读取无会话 RPC，不试开 Fast、不发送模型请求。

点击开关通过 OMP 原生 `set_fast_mode` 启用或关闭 Fast。已有连接直接复用；尚未连接时，明确点击可建立或恢复该聊天的连接，但不发送输入框草稿。仅打开模型面板不建立聊天连接。选择了另一个模型时，只允许空闲原生会话先切到该模型并保留所选 effort；忙碌时不替换当前工作的模型。

闪电选择态使用原生确认的请求状态；只有当前模型的 `fastModeActive` 明确为 true 时，滑轨启用 Fast 效果并将粒子、流线速度加倍。实际生效未知或为 false 时不加速。保持原有 30/60 fps 上限、性能模式、减少动态效果和后台暂停；动画速度不表示模型实测输出速度。

确认前禁用重复操作；失败保留原生旧值，超时或缺少有效回复继续等待匹配确认，不自动重发。重置按钮恢复默认思考强度，并在 Fast 已开启时请求原生关闭。上下文圆环弹窗保留上下文管理和统计，不再显示「原生运行选项」、重试、Slow 或缓存预热控件；OMP 原生策略照常运行。

## 原生目标

平时不显示顶部「目标」入口。输入 `/goal` 或在命令建议中选择它，进入目标模式；随后发送的正文作为原生目标，也可直接提交 `/goal 正文`。目标模式、当前原生目标或本次连接中明确观测到的完成结果存在时显示入口，点击在按钮旁弹出目标状态、可选预算及暂停/恢复/放弃动作；不再另填一份目标正文。完成后按钮显示「目标已完成」，保留到新目标或切换原生会话；放弃不会留下完成标记。仅激活模式或打开面板不会启动 OMP 或模型轮次，明确提交正文才会启动或恢复连接。旧版明确返回未知命令时，提示升级并重启应用，普通聊天继续可用。明确观测到 OMP 禁用 `goal.enabled` 后，隐藏命令建议、保留未提交正文并阻止重复操作；启用后需重新连接会话。

状态、目标 ID、已用 token 和时间均来自 OMP 最近一次报告，用时支持小数秒。原生记账刷新可在仅用时增长时推送更新，但静默期没有实时计时保证；手动刷新只读取原生已记账快照。预算计入新增输入、缓存写入与输出，不计缓存读取。达到预算会让 OMP 收尾并停止目标续跑，不保证立即中止进行中的模型请求；「已达到预算」不等于「已完成」。GUI 不自行估计目标完成百分比。已用完预算的目标即使暂停也不能通过恢复重新开始；需放弃后用新预算创建目标，新目标用量从零开始。

暂停或放弃目标不会 abort 当前模型轮次。需要中断当前执行时，使用会话现有停止动作；原生停止会同时暂停 active 目标，停止按钮和目标面板均提示这一行为。恢复进程后，原生恢复为暂停的目标等待用户明确恢复；GUI 不自动续跑。通过目标模式提交正文或点击「恢复目标」时，若 OMP 已开始或排定工作，不再另发消息；仅在操作前后原生均确认空闲、期间未开始过任何轮次且目标与连接未变时，按正常用户消息路径开始一次工作。创建使用提交的正文，恢复使用「请继续推进当前目标」。结果未知或迟到确认时不补发。后续自动轮次仍完全由 OMP 原生 `goal.continuationModes` 配置决定，GUI 没有续跑循环或定时器。

`goal: null` 只证明原生当前没有目标。界面仅保留本次连接中明确观测到的 complete/dropped 终态，不根据空值、token 数量或回复文字判定完成；更换原生会话后清除旧终态证据。操作结果未知时保留输入及请求身份、不自动重发，并阻止误回收进程。

控制前重新只读核对目标身份；若原生返回另一目标的操作结果，明确报错并采用实际状态，不重发。公开接口没有原子 expected-ID 校验，最后一次读取与原生应用之间的并发变化仍可能发生。将来 OMP 新增状态或模式时，面板保留原始值、目标及用量，禁用变更并提示升级 OMP GUI；损坏的身份和计数仍拒绝解码。

目标正文沿用主输入草稿；预算草稿仅在应用本次运行中按聊天保留。目标模式暂不接受附件，移除附件后再提交。输入最多 128 KiB，超限拒绝提交；目标正文最多显示 64 KiB。预算只在创建时设置，不提供原生 RPC 尚未暴露的预算修改、手动完成或调度操作。

## Hydra

Hydra 的主标记与 25 个子代理头像使用 Tivano 原版 Hydra 矢量资源，保留原有名字、顺序、颜色和工作中呼吸环。头像右下角的完成、失败、停止角标使用一体化原生圆形符号，白色勾、叉和停止方块与对应语义颜色的圆底统一居中，不带外圈边框；角标尺寸跟随头像，不随界面文字大小改变。自定义「π 小队」资源仍完整随应用保留，源码切换入口见[图标说明](../design/icons/README.md#hydra-π-小队--pi-crew)。介绍、浮动面板、步骤与报告弹出层，以及设置页分组沿用 Tivano 的交互。点击聊天顶部的 Hydra 标记显示或隐藏浮动面板；没有 head 时打开原有说明。没有独立工作台、搜索/筛选、额外元数据卡片或新任务表单，任务从正常聊天输入框提交。会话侧栏的连接线等当前细节保持不变。

设置中的 Checkout、Heads at once 和自动应用分别读写 OMP 的 `task.isolation.enabled`、`task.maxConcurrency`、`task.isolation.apply`；面板、自动清除和侧栏显示选项仅影响 GUI。模型配对复用原项目的编辑器和模型选择器，只提供 OMP：主模型用于聊天，子模型与 effort 作为原生 `task.agentModelOverrides.task` selector，配对上限作为该聊天的原生并发 override，不超过已读取的原生总上限。未选择配对时继承 OMP 的模型定义和并发配置。没有恢复旧运行时、GUI 调度器、逐条强制委派或应用自建合并。

Hydra 开启时添加原生委派偏好，关闭时继承 OMP 配置；运行中的子代理不因此停止。OMP 继续决定委派、模型解析、隔离及结果应用。步骤弹出层和浮动面板仅在可见时按原生字节游标补读日志，各自释放读取租约。停止/追加指令同时要求当前父进程支持和匹配 observation；请求接收不代替原生生命周期终态。

同一原生子会话被消息唤醒、继续执行时保留页面、名字及头像；执行轮次和控制 observation 分开记录。一个 `task` 调用派出多个子代理时，派遣行显示多个头像及数量，弹出层可选择其中任意一个；重开主会话后仍按保存的原生工具身份恢复关联。旧版为同一日志创建的重复页面合并到最初的页面显示，原记录及文档保留，不在启动时扫描或批量回填日志。

会话流中的子代理派遣入口仅卡片本体可点击，右侧行内留白不打开子代理步骤；长任务名仍在卡片内单行截断。步骤弹窗复用卡片锚定的原生 presenter，在显示前测量内容并选择屏幕内可用的方向；打开后保持视口高度，新增步骤在内部滚动。批量派遣选择不同子代理时共用 520 pt 步骤视口，仅所选日志持有读取租约。工具图标按首行文字的字形中心对齐，多行文字仍以首行为准。

同批仍有子代理工作时，连续成功完成的提示合并为一行，保留完成顺序；失败和停止各自显示，不计入成功数量。派遣与完成行的头像间距为 6 pt，最多显示四个，其余以 `+N` 表示。完成报告弹窗在显示前测量固定视口并根据锚点所在屏幕的可用空间选择打开方向，不在打开动画中再次按初始内容高度定位。多份报告在同一弹出层逐条独立展开／收起，每条正文渐显／渐隐，箭头与卡片高度使用共享面板动画；收起时正文裁切在当前卡片内。滚动视口保持打开时测量的有界高度，不逐帧调整原生弹窗；减少动态效果沿用共享缓动，性能模式即时切换。单份报告直接完整显示，长报告有界滚动。精简卡片的步骤竖条和完整步骤视图一样，在可见时读取原生日志，隐藏后释放读取，不以进度通知中的总步数虚构日志步骤。

已结束的子代理可在父进程释放后读取选中的原生日志。读取只限当前 edition 的 `omp/sessions/`，解析在后台执行，上限为 64 MiB / 50,000 个条目，隐藏后取消读取。加载、空日志及损坏/超限有明确提示；读取失败保留已有可读历史。原始时间戳和 assistant 的 stop/error/aborted 边界用于恢复轮次与耗时，完整交付报告和后续确认回复各自保留最终答案；缺少时间戳时只显示结果，不编造工作秒数。

父代理通过 `agent://` 送达的可见追加指令按原生消息正文显示为输入，不带 IRC 协议包装；普通 steering 用户消息同样保留。上一轮结束后的新指令显示在下一轮过程折叠区外，工作中的追加指令保留在当前轮的到达位置。生命周期完成通知先更新子代理状态，最后一批日志读完后才结算显示轮次；通知抢先到达或读取期间到达都不会把同一次工作拆成多段。取消且缺少最终回复时，也在补读日志后保留一个中断轮次。

再次打开已恢复的 worker 时，后台按完整日志行的摘要检查变化；未变化则保留原有消息对象和排版，不清空重放，也不把未完成的尾行视为新历史。摘要与原生会话文件绑定，真正变化才重建，公式密集会话的[等待态](markdown-rendering.md)会覆盖重建过程。

GUI 新启动的 OMP 主会话通过私有 `--config` 设置 `providers.openaiLiveSteering: false`，作为 Codex native lane 的兼容降级；此项独立于 Hydra 委派开关。追加消息继续由 OMP 管理，在后续工具边界消费，普通 WebSocket 流式回复保留，原生子代理继承该设置。活动 profile 不变，已有运行进程不会因本地代码合并自动更换配置。详见[通道排错](troubleshooting.md#codex-模型通道的运行中消息拒绝)。

## 文件共享与任务清单

文件预览菜单可把文件位置或源代码选区加入提问，保留绝对路径、行号、原文和来源 worktree。Markdown 选区使用源代码模式。仅打开预览不会自动共享内容；共享后有标记及清除入口。

成功注册后，原生 host tools 可读取明确共享的上下文或在相应 worktree 打开位置。跨目录与符号链接检查保留来源身份，切换聊天不会把旧请求改指向新项目。[文件预览](file-preview.md)说明读取、格式和资源边界。

任务清单投影 OMP 原生 todo。完成后原生清空清单时，GUI 可保留最后一次全部完成的显示快照；新清单替换旧快照。GUI 不把历史展示记录写回 OMP 的活动 todo。eval 的嵌套操作及工具结果仍以原生状态/日志为准，不根据模型文字判断完成。

本页说明当前代码行为；支持版本及未完成的真实窗口、辅助功能和性能验收见[当前状态](status.md)。
