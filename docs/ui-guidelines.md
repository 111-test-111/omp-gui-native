# 原生 UI 与文案约定

界面修改以 [AGENTS.md](../AGENTS.md)为准，复用 [Chrome](../OMPGUI/UI/Chrome/Chrome.swift)、[字体](../OMPGUI/UI/Theme/TypeScale.swift)、[主题](../OMPGUI/UI/Theme/AppTheme.swift)及现有 Hydra/图标资产。源目录分层见[架构](architecture.md)。

## Liquid Glass 的范围

| 表面 | 约定 |
| --- | --- |
| 紧凑单行操作按钮 | 显式使用共享 capsule/circle/rounded-rect 玻璃样式或对应紧凑原生 button style |
| 单行输入与搜索、secure field | 共享 `.textFieldStyle(.chromeGlass)`或 Chrome 搜索控件；胶囊轮廓，无按钮 press 效果 |
| 多行编辑器 | 复用既有窗口圆角与编辑/焦点行为；除下述聊天输入区外，不将新增长区域变成玻璃面板 |
| 聊天输入框与附属队列／改动标签 | owner 明确放宽：共享 `chromeFloatingGlass`，仅在本地 `GlassEffectContainer` 内合成；编辑器和队列无按压反馈，改动标签保留按钮交互；性能模式／减少透明度使用实色回退 |
| Git 侧栏提交信息输入框 | owner 明确例外：共享非按压式 Liquid Glass 输入表面，保留原生编辑与性能模式回退；右下角 AI 图标仍为无底框纯图标 |
| 侧栏等待批准/回答 | owner 明确例外：琥珀色/紫色、非交互 Liquid Glass 胶囊 |
| 输入框内置快捷键标签 | owner 明确例外：与可编辑快捷键同款原生玻璃胶囊，浅色模式呈白色；只读，无 hover/press |
| 侧栏「显示更多」操作 | owner 明确例外：淡灰纯文本，无图标、玻璃或按钮底框 |
| 侧栏「项目／任务」标题的新建操作 | owner 明确例外：与项目文件夹行相同的 `RowAccessoryIcon` 纯加号，无底框；悬浮时显示，菜单打开期间保留锚点 |
| 工作区侧栏页签的关闭操作 | owner 明确例外：小号纯叉号，无玻璃或按钮底框；保留点击范围 |
| 工作区页签右侧的新建操作 | owner 明确例外：纯加号，无玻璃或圆圈底框，悬浮时变为强调色；保留点击范围 |
| 大控件、面板、卡片、内容/空状态、列表/导航行、普通标签/状态、展开区域、页头/页脚 | 原生布局、细微填色与分隔线 |
| 原生 picker 与 switch | 保留原生控件，不外包一层玻璃 |

不要在窗口或整组按钮上继承 glass 样式；逐个指定合格控件。聊天输入区的局部合成容器只合并已明确指定的玻璃表面，不向子视图继承样式。共享实现中还存在服务既有界面的多行 input surface，它的存在不是将任意新容器玻璃化的依据。

聊天与右侧文件区在分栏外共用既有内容表面，透出同一个窗口背景。各阅读器的透明画布与系统内容边界见[文件预览](file-preview.md#renderers-and-scope)；不要逐个给阅读器叠加玻璃或强改 Quick Look 的内部视图。

底栏和侧栏终端复用同一份组件、顶栏间距及无分隔线规范，各自保留独立会话和原生视图；显式迁移按钮才移动已有会话／视图并关闭来源面板。侧栏功能和文件页签的选中标题只变色，不加粗。终端仅将默认单元格背景设为透明，不降低整个终端视图或文字的 alpha。默认文字跟随亮暗外观，光标／选区跟随主题强调色；显式 ANSI 背景保留程序颜色。壁纸、透明度及性能／辅助功能实色回退继续由窗口负责。

主窗口中的聊天／设置页面与壁纸缩略窗口共用 `WindowBackdrop`。壁纸采用高斯模糊，以填充裁切方式覆盖窗口；「柔和度」从最左端的清晰原图逐渐增加到最右端的柔化背景，归零／重置不施加模糊，不修改已存偏好。效果只在有界解码图片上处理一次，缩略窗口缩放同一张处理后的图片；拖动到零时也使用完整解码图片，避免低分辨率预览造成残留模糊。透明度滑块独立控制处理后图片与模糊桌面的混合，0 仅显示模糊桌面，1 完全覆盖桌面，不增加图片模糊；文字和按钮不随背景变透明。深色模式在合成后增加阅读遮罩。性能模式或系统「减少透明度」启用时使用纯色回退，已选图片及柔和度保持保存。

设置页面内容区居中，宽度上限为 800 pt，主窗口较窄时随可用空间收缩；设置导航栏宽度保持不变。 页面正文加入随内容滚动的标题，滚出后由顶栏紧凑标题接续；导航行采用 32 pt 最小高度及清晰的选中／悬浮反馈，保留现有顺序、分组和全部页面。导航搜索同时匹配当前语言的页面名称。

本次打开设置期间，已访问页面按需保留独立的原生宿主，最多为侧栏的全部页面数；不提前构建未访问页面。切换时将旧页移出窗口，沿用离页时的任务取消、登录取消及弹窗关闭，再挂回已缓存的新页，避免销毁整页和清空已加载列表。返回页面仍重置滚动位置、搜索和归档筛选，并按原有规则异步刷新；常规、外观和快捷键的离屏区段采用惰性布局。关闭设置时释放页面宿主；OMP 的首次数据读取仍受原生接口耗时影响，不承诺尚未读取的数据即时就绪。

效果集中在 [WallpaperEffect](../OMPGUI/UI/Theme/WallpaperEffect.swift) 的 `current` 和共享绘制入口，保留以后替换材质的可能；当前不增加只有一个选项的材质选择器。未来原生玻璃效果应在壁纸与桌面混合后采样，不能直接降低整个玻璃层的透明度，也不能分别给聊天和文件阅读器增加背景效果。

所有应用自有 popover 共用 [PopoverBackdrop](../OMPGUI/UI/Chrome/PopoverBackdrop.swift)：SwiftUI 使用 `chromePopover`，原生 `NSPopover` 的固定内容及动态内容根视图使用 `popoverChrome`。背景使用完整覆盖的原生标准磨砂材质，不跟随主窗口的透明度设置；透明感由材质本身提供，底层内容经模糊后透出。已有原生玻璃背景使用 regular 变体，旧材质路径使用 active／behindWindow 的 popover 材质；不使用 clear 玻璃或降低整层效果的 alpha，避免未经模糊的底层文字混回画面。样式依据 [Apple 的材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)。性能模式变化对已打开弹层实时生效。原生玻璃背景与旧材质框架只保留一个有效背景，移除额外的近实色染色；背景分支与前景隔离，材质保持完整覆盖。文字、控件、图片与视频保持原有不透明度，不重复绘制整张壁纸，不为大面板新增 Liquid Glass。原生背景的形状遮罩及伸缩边距保留，前景子树不参与背景查找；[AppKit 的材质遮罩](https://developer.apple.com/documentation/appkit/nsvisualeffectview/maskimage)不遮罩子视图。背景查找有节点上限，关闭／拆卸时恢复原生材质与窗口状态。性能模式或系统「减少透明度」请求实色背景回退；锚点、箭头、测量、滚动与关闭行为沿用各自 presenter。普通 sheet、独立浮动面板及系统菜单不属于这个 popover 背景入口。

主聊天输入框及其队列／改动标签采用共享 `chromeFloatingGlass`：原生 regular glass 只采样一次，主题染色与细边框保持轻微，标签被输入框覆盖的底边不重复绘制边框。文字、附件和控件保留完整不透明度；玻璃下不再放近实色遮罩。已位于玻璃面板中的辅助编辑器保留平面控件填色，避免重复采样。步骤树、运行状态卡片、设置内容和审批表单继续使用普通原生表面，现有 popover 背景契约不变。

紧凑操作优先用 `ChromeButton`、`ChromeIconButton`、`ChromeSearchField`、`GlassPickerButton`等已有控件。普通容器用 `ChromeCard`、`ChromeSection`或简单原生布局。单行输入沿用胶囊，多行表单沿用 `Chrome.windowCornerRadius`，不要在每个页面复制常量。

设置卡片和同类列表行统一使用 `ChromeRowDivider`，左右各留 16 pt。插件范围使用共享 `PopoverMenu` 展示活动 profile／项目选项，触发按钮沿用同一行操作的原生 `.glass` 内边距；打开选项不读取或切换 OMP profile，只有选择范围后才刷新插件列表。

工具目录每项固定单行：名称后紧跟调用方式与状态两个普通标签，原生开关／选择器靠右排列，不展示工具描述。长名称单行截断，悬停可读完整内容；依赖条件和共用范围并入提示。记忆、图片生成等由其他设置页管理的能力仅显示状态及管理入口提示，不重复提供开关。

MCP 安装与单服务器编辑器均从各自按钮锚定弹出，标题使用正文字号；长表单在内部滚动，操作按钮固定可达。仅保留靠右对齐的传输方式选择器；stdio 使用统一的命令／参数表单，填写 `npx`、`uvx` 或其他可执行命令即可，不再单独选择安装方式。新建默认 stdio，命令为空。弹窗仅提供可视化表单，页头的“打开 JSON 文件”按钮交给系统默认应用打开活动 profile 的 `mcp.json`。超出可视化行数限制时，弹窗仅提供文件入口及取消操作。该页不再提供内嵌 JSON 编辑器或刷新按钮；保存后立即更新列表；应用预热并共享一份活动 profile 缓存，跨页保留单一文件监听以跟踪写入／原子替换／删除，文件事件直接重读 JSON。返回页面和应用恢复活动时在后台核对 profile，已加载列表不清空、不显示刷新占位；可执行文件／环境身份变化时立即失效。首次预热未完成时仍需原生读取。自动刷新保留已打开表单的原快照及冲突检查。预设连接／登录表单及已识别目录服务的授权弹窗显示该预设记录的完整工具名，沿用卡片字体并有界滚动；使用现有窗口坐标锚定的原生弹窗，关闭时不触发设置滚动区的焦点定位。

活动 profile 的配置路径使用界面正文字体，与安装／打开 JSON 文件按钮一同位于服务器区域上方。服务器列表与无配置／无搜索结果提示共用一个浅色 `ChromeCard`，空状态水平、垂直居中；该页不提供文档或终端入口。

MCP 条目的名称及第二行命令／主机信息均使用界面字体。右侧依次为铅笔编辑、眼睛启停及红色删除图标，均使用共享圆形玻璃按钮。启用时显示睁眼，禁用时显示闭眼，与模型条目一致；提示说明下一步启用／禁用操作，辅助功能值报告当前状态。删除位于最右侧，仍需确认。保存及自动刷新期间保留已加载控件的外观，操作入口继续防止重复提交；不因临时 I/O 忙碌反复切换整个按钮组的禁用态。

MCP 编辑器单行输入框不显示占位文字，保留独立的辅助功能标签。滚动内容两侧各留 8 pt 供玻璃外沿绘制，同时将视口向外扩展相同距离以保持与固定页头／页尾对齐，不关闭纵向裁切。本地服务器的参数、环境变量及远程服务器的 HTTP 请求头为空时，各提供一行空输入；npx 不预填 `-y`。自动生成且未填写的行不保存，已有的空字符串参数以及名称已填写而值为空的环境变量／请求头仍需保留。

Hydra 顶栏按钮的圆形玻璃在局部 `GlassEffectContainer` 内合成，任务角标放在该容器之外、仍属于同一个按钮。角标不进入玻璃按下时的圆形裁剪，也不被顶栏其他玻璃盖住。

快捷键组合控件与内置快捷键标签统一使用左右半圆的胶囊轮廓和主文字色；内置标签使用共享 `.chromeGlassFieldCapsule()`，与上方可编辑控件采用同款原生 regular glass 和主题 tint，浅色模式呈白色。内置标签保持只读、不添加悬停／按压效果；可编辑控件保留录制高亮，两者均沿用共享性能模式回退。

等待状态使用 `chromeGlassStatusCapsule(tint:)`，不带 hover/press；其他状态标签不沿用这个例外。审批与问答 popover 的内容区保持普通原生表面，决策按钮紧凑且始终可达。

## 交互、可访问性和资源

- 文本、背景与状态使用共享语义颜色。可见文字、图形和辅助标签共同传达状态；颜色不替代名称。
- 保留性能模式、减少透明度和减少动态效果的既有回退。自定义 AppKit 宿主同步主题、可见性、焦点和 teardown，不只处理 SwiftUI 的 `onDisappear`。
- 窄布局保留动作入口；popover 消失后焦点返回合适位置，Escape、键盘提交和多窗口请求状态不能串扰。
- 长工具详情、选项、报告和目录有界滚动；预算按字节/数量声明，不以截断后的文字替代待提交原文。
- 隐藏视图释放额外读取与订阅租约，延迟结果带身份校验。测量/轮询不能随新页面默认开启。

新的 UI 字符串按[本地化约定](i18n/CONVENTIONS.md)手动加入 zh-Hans。用户内容、文件路径、模型名及 OMP 原生消息使用 verbatim，不能作为动态本地化键。

[图标说明](../design/icons/README.md)记录已批准资产；不改上游图标。工具行按 [OMP_TOOLS.md](OMP_TOOLS.md)精确身份选用原生 SF Symbols，不从标题猜测。`find`／`glob` 使用空心 `folder` 加右上角实心放大镜／星号圆标，圆标较原生文件夹角标参考增大 30%；`read` 使用 `text.menu`，`analyze_files` 使用 `text.menu` 加同尺寸的右下角实心放大镜圆标。自定义组合采用空心主体和实心圆形角标，保留透明挖空和原生字重；除 analyze_files 的指定位置外，角标通常放在右上角。工具、思考、信息/系统通知、警告、错误及计划行共用 12 pt 符号字号和 16 pt 槽位，符号字号跟随聊天内容字号设置；Hydra 工具步骤与会话记录中的原生工具图标沿用相同呈现。展开箭头和状态标记保留各自尺寸，Hydra/MCP 专用资产保留。

提供商、MCP、项目选择器等可配置标记的单色图形使用模板或 SF Symbol，随共享语义前景色切换外观；彩色资产及 emoji 保留原色。下载的单色网页图标也遵循此规则，原生附件在绘制时解析所在视图的外观，不把某次主题颜色烘焙进缓存位图。

按钮触发的 popover 先附着到按钮自身，再应用用于对齐的外层 `frame` 或不对称 `padding`；不要把空余布局区域算入锚点。插件范围、共享胶囊选择器与浮动子代理面板的关闭确认均遵循此顺序，系统仍负责屏幕边缘避让。

## 字体

界面一律使用系统默认字体。“设置 → 外观 → 字体”中的等宽字体可自由输入，支持本机字体内记录的中英文、简繁体本地化家族名、完整名称或 PostScript 名称；忽略大小写及首尾空白。家族名采用该家族的默认字形，完整名称或 PostScript 名称可指定具体字形。留空或无法匹配时恢复系统默认等宽字体。选择即时生效并保存到当前 edition 的偏好，不修改 OMP 配置。

- 等宽字体用于代码、差异、源码预览及行号，并覆盖已打开和隐藏的底栏终端。
- 字体家族与现有三个字号设置独立；“重置字号”只重置字号。终端保留其原默认字号，字体变化不重启 shell，也不替换终端视图。
- 等宽字体缺少的字形由系统回退链补足；已有的等宽字形、字号和终端单元格宽度不变。
- SF Symbols 和 emoji 保留系统字形；PDF 原文、实际数学公式、Quick Look/媒体内建控件、系统菜单及系统弹窗保留各自排版，不承诺受等宽字体配置控制。

实现复用 [AppFont / TypeScale](../OMPGUI/UI/Theme/TypeScale.swift)及现有 `.ui` / `.chat` / `.code` 工厂，不在视图中直接解析用户输入。SF Symbols 使用 system-only `.symbol`；界面文本始终解析为系统字体，原生等宽文本的测量与渲染采用同一字体。字体敏感缓存和原生宿主更新跟踪 `AppFont.revision`；WebKit 通过本地 face 别名更新 CSS，不重载文档或丢失选区。

## 代码高亮

“设置 → 外观 → 代码高亮”提供 GitHub、Atom One、Solarized、Catppuccin 四组知名配色，默认 GitHub。每组随当前界面使用浅色／深色版本；Catppuccin 对应 Latte／Mocha。选择即时生效并保存到当前 edition 的 `codeHighlightTheme` 偏好，不修改 OMP 配置，也不改变应用本身的主题。

[CodeHighlightTheme](../OMPGUI/UI/Theme/CodeHighlightTheme.swift)是普通代码文字、注释、字符串、关键字、数字、类型及属性／注解颜色的唯一来源。[CodeSyntaxStyle](../OMPGUI/UI/Common/CodeSyntaxStyle.swift)为聊天围栏代码、展开的读取工具输出和原生源码预览提供动态颜色；Markdown 文档预览从同一组值取得 CSS 变量，不维护另一套配色。原生和 highlight.js 的分词规则仍各自保留，不承诺不同引擎的 token 边界完全相同。

切换配色复用有界的原生扫描结果，WebKit 只更新当前文档的样式；不重建源码文本或 Markdown DOM。原文、复制、选区、滚动位置、字体及透明画布不变，代码块沿用已有内容底色。正文行内代码、差异增删的语义色和终端 ANSI 配色不属于此选择器。


## 验证

## 用量统计

“设置 → 用量”独立于“通用”，包含 7 天／30 天／90 天／全部时间的统计范围、token 总量及上一时段变化、已记录输出、缓存命中率、活跃天数、每日堆叠趋势、token 构成环图、会话／轮次／模型数量、日均用量、子代理占比，以及模型／服务商／项目排行。顶部与各统计分区的小标题沿用其他设置页的灰色次要文字，范围选择器与年度活动共用右对齐的标题行；独立的右上角 Chrome 刷新按钮同时显示“刷新”和更新时间。图表使用 Swift Charts，范围和热力图模式使用原生分段选择器，指标仅用轻微填充，上下统一使用 16 pt 内边距，末行说明按实际行高排版。窄页面将并列区块改为纵向排列，排行最多显示前八项及合并的“其他”。每日趋势的空白区悬停不改变柱色，只有命中的实际柱体加深并显示竖向定位线；点击柱体后才打开原生 Chrome popover，显示日期、总量及输入／缓存／输出／未分类明细。弹窗锚定柱体上部，优先朝图内空间更宽的一侧展开，窗口边缘避让沿用系统行为；所选柱在弹窗打开期间保持高亮，点击外部或按 Esc 关闭。各有用量日期提供原生按钮语义，键盘与辅助功能可打开相同详情。辅助功能保留各个统计项及图表数据。

进入用量页、统计范围切换或手动刷新完成后，图表播放一次约 0.65 秒、短暂错开的渐入：每日柱图柔和展开，环图按弧度显现，排行与热力图从左向右显现，指标卡片的表面保持静止，只有数值与说明文字渐入，数字平滑过渡。年度热力图的分组模式切换也使用相同过渡。普通实时更新只插值数据和数字，不重复播放整组渐入；等待读取时保留现有内容。动画不修改真实统计数值、图表坐标或布局尺寸，也不重建页面与滚动状态。离开页面会取消待播任务，系统“减少动态效果”或应用性能模式下直接显示最终状态；不使用持续动画或常驻计时器。

年度 token 活动保留每日／每周／累计三种模式，始终覆盖当前本地自然年，不受顶部范围影响；年度总量也仅累加该年。月份使用系统日期格式，单个 Canvas 有界绘制且不运行持续动画。全部时间的总计包含更早历史，趋势标题旁以“90 天”标明绘制范围。页面移除常驻的来源、缓存定义和未记账轮次数说明，读取失败、预算截断或无效记录仍保留实际异常提示。

来源仅为本 edition 资料库保存的 OMP 轮次，包括已归档聊天及独立的原生子代理；已完整加载的运行时快照替换磁盘副本。旧版内嵌轮次和当前按 revision 保存的轮次均可读，同一 GUI 轮次或同一原生会话用户条目去重，旧原生子代理别名仅取保留最完整的一份累计记录，不读取 Codex、Tivano 或其他产品的历史。删除／回退的会话记录不再参与统计，因此这里是保留历史的用量视图，不是独立的账单账本。

日期按轮次开始时间归入本地时区；模型与服务商按该轮次已记录的逐模型用量归属。缓存读取包含在输入中，堆叠图不重复相加；缓存命中率以带有效缓存明细的输入 token 加权，未知值显示为“—”，缺少分类的总量归为“未分类”。不从模型价格推测费用，也不把轮次称为请求数。零用量、未记录用量与读取失败分别呈现。

打开页面、可见期间的轮次／资料库变化以及手动刷新会在后台更新，短时变化合并，离页取消并拒绝迟到结果。读取只解码记账字段并缓存未变更的资料库文件，最多 2,000 个聊天、50,000 个轮次、单文件 32 MiB、每次新读取 256 MiB；触及上限或文件不可读时保留可用数据并明确标示统计覆盖不完整。不会启动 OMP、扫描外部配置或发起模型请求。

## 调试详情间距

调试详情统一使用区块间 16 pt、小标题到内容 8 pt、字段名到值 4 pt；同一区块内各行相隔 8 pt，列表行不叠加额外纵向 padding。没有可展示参数、停点字段或结果条目的区块整体隐藏，标题不单独占位。原始响应仍使用可折叠区域。过程列表没有摘要时只保留单行标题，详情页保留动作的时间与耗时。
