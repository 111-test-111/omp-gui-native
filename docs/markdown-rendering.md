# 聊天 Markdown 与公式

本页描述聊天回复。文件中的 Markdown 有独立的[离线 WebKit 预览](file-preview.md)，使用 markdown-it/MathJax；不能把其语法范围直接套用到聊天。

## 原生渲染路径

[MarkdownParser](../OMPGUI/UI/Markdown/MarkdownParser.swift)产生 `MarkdownBlock`，行内语法交给 Foundation，再通过 SwiftUI / AppKit TextKit 1 显示。[MarkdownView](../OMPGUI/UI/Markdown/MarkdownView.swift)、[连续正文](../OMPGUI/UI/Markdown/ProseRunView.swift)和[段落布局](../OMPGUI/UI/Markdown/MarkdownParagraphLayout.swift)复用原生选择、链接、流式及主题行为。产品没有替换为第三方完整 Markdown AST。

完成的回复把含行内公式的相邻段落、标题及可合并列表放进连续原生正文，避免每段公式各自创建文本和滚动宿主；选区可跨段落，公式仍按原始 TeX 复制。引用保留带边线的容器；块公式、表格和代码仍单独显示。超宽公式的原生绘制/命中几何按布局失效及容器宽度缓存，正常滚动和选区变化不再扫描整段附件。

普通正文、链接和行内代码的 SwiftUI 宽度试算使用独立 TextKit 布局，不修改正在显示的文本容器或选区。每个正文视图按内容/附件几何修订缓存最多 8 个宽度结果，内容或字体变化后重新测量；原生 `layout()` 只按实际分配的宽度提交显示排版，避免长回复在反复宽度试算间重排全文。固定长正文的离屏对照选择 `make verify TIER=benchmark AREAS="chat-prose-layout"`；结果仅描述 TextKit 试算成本，不代表完整应用滚动帧率。

会话文本的自动换行保留 3 pt 行间留白；显式手动换行使用 2 pt 留白，用户多行纯文本、助手正文、列表续行和围栏代码沿用这一规则。段落间距为 14 pt、有序／无序列表项及嵌套内容间距为 8 pt，引用／提示块内的块间距及表格行距为 12 pt。SwiftUI 与 TextKit 共用[段落排版规则](../OMPGUI/UI/Markdown/MarkdownParagraphLayout.swift)：原生正文的显示、宽度试算与固有尺寸测量使用同一行尾回调，避免连续正文额外计入行尾留白，列表条目边界不叠加正文的行尾留白，不随正文手动换行设置变化；纯文本、加粗、代码及链接条目统一使用原生段落排版，使流式／分段列表与完成／连续列表保持相同的较小间距。装饰标记去除多占的底部留白，避免单行条目比自动折行条目更松。仅列表实际末尾使用段落外间距，含子项的最后一个父条目保留列表内部间距。含显式换行的普通 Markdown 及用户消息也使用原生文本，保留自动换行、用户消息的字面标记和链接文本、列表缩进及原始选择／复制内容。

用户消息按纯文本显示，保留 Markdown 标记和换行，不自动解析链接；助手回复使用上述 Markdown 路径。运行中的中间回复按时间顺序显示，完成后收进过程区，最终回复单独显示，详见[时间线与过程折叠](chat-workflows.md#聊天时间线与过程折叠)。仅标点/空白的回复不产生可读消息行。相关组合在 [TimelineRows](../OMPGUI/App/Views/Chat/TimelineRows.swift)和[文本清理](../OMPGUI/Core/Support/Text.swift)。

| 语法 | 当前行为 |
| --- | --- |
| 标题、段落、列表、引用、围栏 | 原生块模型；列表/引用容器仍是简化实现 |
| Setext 标题 | 段落后的纯 `=` / `-`转为一/二级标题；独立分隔线保持分隔线 |
| 本地文件链接 | 沿用正文常规字重，保留主题链接颜色与原生点击预览；路径、`file://` 及行号链接采用相同样式 |
| 网页链接 | 标题前显示已加载的站点图标；单色图标随亮暗主题适配，彩色图标保留原色；图标保持 14 pt，移除额外的 1 pt 上移以修正中心偏高；按可见图像及相邻字形边缘，使左侧留白与原有右侧留白相等，复制保留原有空白 |
| 表格 | 列对齐、转义竖线、按实际内容测量固有列宽；仅内容超过可见宽度时横向滚动；公式内竖线先保护 |
| 提示块 | 顶层 NOTE/TIP/IMPORTANT/WARNING/CAUTION；未知或嵌套形式保留引用 |
| 缩进代码 | 四列/tab，保留内部空行及列表相对缩进 |
| 换行 | 软换行折为空格；两个尾随 ASCII 空格或反斜杠形成硬换行 |
| 加粗 | 成对 `**` 兼容中文标点紧接正文及标记内部空白，例如 `**符号模板：**先将…`、`** 标题： **`；保留嵌套格式和链接，代码、转义及链接目标不参与修复 |
| 公式 | 下述 MathJax 公式附件 |

下载的 GitHub 等单色站点图标通过[共享图标处理](../OMPGUI/UI/Common/AdaptiveIconImage.swift)保存为透明模板，保留内部镂空。正文附件每次绘制按文本视图的实际外观解析颜色，已缓存段落也能立即切换亮暗；链接弹出菜单使用同一模板。单色和彩色正文附件均保留基线偏移的小数精度，避免原生 cell 取整造成垂直位置偏差。彩色标记不转成单色，白色前景不会仅因碰到图像边缘而被当成白色底板删除。

引用式链接、脚注/标题锚点、定义列表、图片布局、完整 HTML、Mermaid 等不是当前聊天渲染器的完整兼容承诺。继续扩展全局/嵌套语义前重新评估 AST 与流式缓存边界。

## 代码与流式

[InlineCodeStyle](../OMPGUI/UI/Markdown/InlineCodeStyle.swift)统一动态灰色及较小等宽字体，不使用独立背景。行内代码沿用原生文本基线，不再额外上移；原生 TextKit 与 SwiftUI 样式路径保持一致。含行内代码的内容统一使用原生 TextKit，与链接、公式及连续正文共享选择、流式和外观行为。

同一正文字号的所有行内代码，在不同片段、段落和消息中采用相同的可见留白。目标为正文字号的三分之一，默认 15 pt 正文对应两侧各 5 pt，并随正文字号同比例调整；修改等宽字体或代码字号不会扩大目标留白。实际边界仍按完整段落的字形边缘测量；中英文标点或全半角字形的侧留白超过目标时，只用无字形显示空白的有符号字宽补偿，保持文字字形及代码内部字距完整。相邻代码共享一次间距，单字符分隔符两侧、括号或引号内的多个片段也沿用同一目标。

边界空白只用于显示，并保存原文映射；源 Markdown、代码内部字符、组合字符和 Emoji 保持完整，选区复制及富文本导出恢复原有字符与空格。相邻正文括号固定边界字宽，界定符的测量与显示使用同一实际回退字体，避免括号换到行首后再次压缩内侧间距。少数字体的全角字符需要负的字形起点才能保留紧凑留白；若 TextKit 把起点夹到行首，则在本行布局完成后按显示空白的有符号字宽还原，不改字体、字形或代码内部字距，也不跨换行应用。聊天列变宽或变窄时，统一留白目标保持不变，由 TextKit 重新换行，行首不会带入人工补齐的空格。

表格中原生代码、链接单元格的自然宽度由独立 TextKit 布局测量，并按已渲染内容缓存；宽度探测不改变正在显示的文本容器。单元格保持完整内容所需的自然宽度，保留源文中的显式硬换行；侧栏变窄时通过整表横向滚动展示长内容，不把列压成许多行。可容纳的短表不产生额外横向滚动范围。

围栏代码复用[语法高亮](../OMPGUI/Services/Files/PreviewSyntaxHighlighter.swift)及[共享颜色](../OMPGUI/UI/Common/CodeSyntaxStyle.swift)，与原生源码、展开的读取工具输出和文件 Markdown 预览共用[可选代码主题](ui-guidelines.md#代码高亮)。缓存保留有界 token 供切换主题时重新着色，不重新扫描未变化的源码；只保留每个代码片段最近使用的配色，不按主题倍增缓存。工具调用的代码/参数展示由聊天工具视图单独管理，不能把工具输出都当 Markdown 执行。

围栏语言识别同时接受语言别名和文件名，新增 Makefile、LaTeX/BibTeX、CMake、Dockerfile、配置和更多脚本／科研语言；具体范围及 Markdown 源码／WebView 预览的边界见[文件预览](file-preview.md)。未知语言和明确的纯文本保持原样，不根据正文猜测语言。

[StreamMend](../OMPGUI/UI/Markdown/StreamMend.swift)和[ProseReflow](../OMPGUI/UI/Markdown/ProseReflow.swift)处理流式稳定区与复制，保留 TeX 内部转义。连续正文缓存比较块结构，避免同文字 Setext 标题仍沿用旧字号。不要在每次 token 更新时重排整个历史。

[StreamVeil](../OMPGUI/UI/Markdown/StreamVeil.swift)只为新到文字添加渐显。原生文本的临时前景色逐帧按文本视图自身外观解析，保留正文、链接、行内代码各自的颜色与原有透明度；显示回调所在环境或渐显中的主题切换不会改变这一规则。渐显不改写正文属性、选区或布局，结束后清除临时颜色。

## 原生正文与公式附件

[MathRendering](../OMPGUI/UI/Markdown/MathRendering.swift)保留原生 TextKit 正文、链接、选择和复制；完成的公式由[共享渲染器](../OMPGUI/UI/Markdown/ChatMathRenderer.swift)生成透明图片附件。与[文件预览](file-preview.md)共用固定 MathJax 4.1.3、New Computer Modern 资源和启动配置，全部离线加载。聊天没有渲染器切换选项；SwiftMath 已退出应用依赖，历史基准和原始[许可证](../THIRD_PARTY_NOTICES.md#swiftmath-and-asana-math)继续保留。

[MarkdownMath](../OMPGUI/UI/Markdown/MarkdownMath.swift)在 Foundation 解析前保护 TeX。支持 `$...$`、`\(...\)`及独立行 `$$...$$`、`\[...\]`；代码、围栏、转义美元符、链接目标与网址保留原文。`$20 and $30`这类货币文本不当作公式。

聊天与文件预览共用以下常用记号配置。预载小型 `braket` 扩展，使 `\bra{a}`、`\ket{b}` 和单参数 `\braket{a|b}` 的含义不随物理扩展的加载顺序变化；双参数内积使用 `\innerproduct{a}{b}` / `\ip{a}{b}`。其余扩展按首次出现的命令或环境离线加载，独立公式首次使用也可用。

| 记号 | 支持范围与示例 |
| --- | --- |
| 常用简写 | `\ii` / `\ee` 为正体虚数单位 / 自然常数；`\bm{...}` 等同 `\boldsymbol{...}`；`\argmin` / `\argmax` 支持上下限；`\sgn` / `\diag` 为正体算子 |
| 数学排版 | `mathtools` 命令及环境，包括 `\coloneq`、`\xRightarrow`、`\overbracket`、`\splitfrac`、`dcases`、`rcases`、`pmatrix*` 和 `multlined` |
| 物理记号 | 微分 `\dd` / `\dv` / `\pdv`、取值 `\eval`、括号 `\pqty`、矩阵 `\mqty`、对易子 `\comm`、向量 `\vu`、迹 `\Tr`、内外积及矩阵元等公开 `physics` 命令 |
| 字体与单位 | `\mathbbm` / `\mathds` 指示函数字体、`\nicefrac`、`\units` / `\unitfrac`、`\degree` / `\celsius` / `\ohm`、`\upmu` 等正体希腊字母，以及 `\centernot` |

这些简写是渲染器的默认宏，可在当前公式用 `\renewcommand` 覆盖；不会读取项目的 TeX 导言区、`.sty` 文件或其他消息中的定义。其他自定义宏须在当前公式内显式声明。未知命令、无效/过于复杂的公式和不支持的完整 LaTeX 文档/绘图语法保留原始文本，使用正文常规字体、字号和颜色，不套用行内代码或等宽样式；未闭合公式和等待图片时的临时源码也采用正文样式。标准 AMS、分式、矩阵、颜色及化学公式沿用原有支持。

行内图片按垂直墨迹裁切，保留 MathJax 基线及数学轴的实际位置，将数学轴对齐原生正文字体的 cap-height 中心。逗号、上下标和高分数改变图片外框时，不再拖动原有变量的垂直位置；完整图片参与行高测量。两侧透明边距各 1 pt，保留 TeX 的水平 advance；聊天将 `\qquad` 从 2 em 收紧至 1 em，原始 TeX 及复制内容保持不变，文件预览仍采用标准间隔。块公式居中；超宽公式保持字号并横向滚动，正文仍按可见宽度换行，作者可用 aligned、cases 或矩阵显式分行。

公式宿主用独立 TextKit 布局试算 SwiftUI 的候选宽度，按正文/图片几何修订清空测量缓存，最多保留 8 个宽度结果。试算不改正在显示的文本容器、文档 frame、滚动条或布局失效状态；只有原生 `layout()` 才按实际视口提交几何。表格的固有宽度探测和最终视口因此不会相互触发布局循环。回归与真实会话重放见[聊天布局卡死修复](archive/chat-layout-hang-2026-10-18.md)。

附件默认每点 2 像素；1×/2× 屏幕复用同一图片，高于 2× 时按实际倍率重新生成，最高 4×。隐藏 WebView 的绘制区域按整批公式实际宽高扩展，避免超宽或超高公式被视口裁掉。截屏前按本批实际文字显式等待所用字体和字形，再等待浏览器字体就绪，避免首次使用的算子、粗体或指示函数字体漏字。快照宽度向上取整，保证像素密度；升级期间继续绘制已有图片。字号变化使用新的几何和图片。普通墨迹在原生绘制时应用主题、前景透明度及流式渐显，显式 TeX 彩色内容保留，选中时全部墨迹使用原生选中文字颜色。透明边缘不会带入白色或黑色矩形底色。

共享 worker 优先处理可见附件，首批最多 8 个公式，后续每批最多 64 个，复用解析器和字体，以 MathJax 的 `begingroupSandbox` 隔离每个公式的本地及全局定义。图片在同一截图中紧凑排列，复制和蒙版处理在后台进行；普通黑色墨迹使用 Accelerate 提取 alpha，显式彩色内容保留独立蒙版。超出图片预算时按半拆批，单条失败也会结束等待。完整公式在等待图片时暂显源码，异步完成只失效相关文本视图的布局，不替换正文或选区。未闭合输入不进入 MathJax。复杂度限制 16 KiB、64 层花括号；每批最多 1,600 万像素、单边 16,384 像素。失败保留原始源码，可继续复制。

图片缓存按 TeX、text/display、字号和像素倍率区分，内存目标限制 2,048 项、估算像素成本 64 MiB；等待中的相同请求合并，避免缓存压力导致重复排版。这不是全部可见附件或整个进程的内存上限。聊天打开时可从最近完成回复的前 8,192 个字符预取一个完整公式；页面导航同时开始准备 MathJax。

像素和基线/数学轴信息还保存在当前 bundle ID 的系统 Caches / ChatMath 目录，版本命名空间内限制 4,096 项 / 128 MiB，单文件 16 MiB。文件名为缓存键的 SHA-256，文件不保存 TeX 文本或会话标识。缓存读写在后台执行；命中时无需启动 WebKit，损坏、过期或缺失的记录重新排版。修改 MathJax、公式配置、字体或图片几何协议时需更新命名空间。宽度、主题和选区变化复用图片，字号/倍率变化使用各自缓存。最后一批工作完成后闲置 60 秒释放隐藏 WebView、窗口及资源请求，已有原生附件仍可绘制。

公式密集会话使用[会话等待态](../OMPGUI/App/Views/Chat/ChatMathLoading.swift)。进入/启动恢复时，对最近 4 条完成回复各采样前 32,768 字符；发现至少 16 个完整公式后，立即显示 3×3 波纹图标和「正在等待会话加载」。首次构建密集原生时间线前让提示先提交一帧；已有时间线继续挂载排版。当前会话的公式图片、初始历史窗口、原生 worker 历史重建和最后一次附件/时间线几何更新后 120 ms 都准备好后显示内容。与其他会话的后台队列无关。

已准备完成的缓存列切回时直接显示，保留就绪记录；原生日志未变化时不清空或重放已有消息。真正的历史替换立即重新显示密集会话的提示；后续字号、倍率或缓存失效产生至少 16 项待处理附件时，持续超过 180 ms 才显示，快速完成不闪烁。无公式、少量公式和流式中的新回复不触发遮罩。已显示的 spinner 至少保留 280 ms；初始分页之间的短暂队列空闲仍属于同一次等待。约 4 秒后显示已有内容，避免异常时一直遮挡。标题、导航和输入框可用，减少动态效果/性能模式使用静态图标。具体状态策略见[准备控制器](../OMPGUI/UI/Markdown/ChatMathPreparation.swift)。滚轮第一拍及触控板 tracking 阶段会取消旧定位任务并阻止底部校正，不把原生回弹误作需要纠正的布局偏移。

选择复制将附件替换为原始带分隔符 TeX，保留相邻 Unicode、链接、硬换行和 RTF；「复制 LaTeX」只复制内部源码。无障碍标签保留原始 TeX，不提供自动数学语音/语义 MathML。

## 验证与历史研究

## 长会话增量准备

沿用现有后台解析、分段历史、独立宽度测量、MathJax 图片与有界缓存。流式 coordinator 的解析结果交给完成回复复用，长历史预热优先处理最近回复，继续遵循原有条数／字节预算。原生富文本只有既有属性前缀完全相同时才追加尾部并保留选区；Markdown 闭合导致旧内容重设样式时仍完整替换。

每个聊天列拥有自己的渐显时钟；列隐藏时撤销显示回调，回来时按真实时间恢复，不重放已经结束的渐显。字符追加只重算尾部字素，处理组合字符、CRLF 和 ZWJ emoji；文字颜色、原有透明度及当前外观保持既有修复。隐藏输入框暂停变更统计；附件及无扩展名文件图标使用有界短期元数据缓存，未找到的文件不缓存为永久缺失。以上是实现与定向检查范围，不能代替整应用可见延迟或 GPU 测量。
