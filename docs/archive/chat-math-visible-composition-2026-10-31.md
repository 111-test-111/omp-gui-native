# 聊天公式可见窗口合成修复

日期：2026-10-31（Asia/Hong_Kong）。版本：OMP GUI Dev 0.1.361 / build 362。环境：macOS 27.2 arm64、Swift 6.4.2。当前行为见[聊天 Markdown 与公式](../markdown-rendering.md)，验证入口见[验证规范](../verification.md)。

## 复现与修正

用户报告同一子代理回复在展开卡片中可见，但独立聊天的行内公式滚入视野后空白。现场确认运行中的 0.1.360 仍有问题；空白公式具有有效图片、布局和绘制调用。此前「原生附件回调被省略」的推断没有解释实际失败，故撤销普通公式的统一补绘，保留超宽公式的必要补绘及原生定位。

最初的 0.1.361 候选只把软裁剪换为直接绘制 CGImage mask，离屏检查通过，真实窗口仍失败。最终实现先把蒙版和显式颜色合成为透明 RGBA 图片，再交给原生图层；按图片身份、颜色和选中状态缓存着色结果，保留调用方透明度。现场对照支持故障位于蒙版进入可见图层的合成路径，不把内部系统机制当作已证实的结论。

另一个完整墨迹检查发现，统一补绘会裁掉部分块公式的顶部：`S\setminus A=S\cap A^{c}` 的归一化 alpha 总量为 137.64，而完整图片为 164.71。恢复 TextKit 提供的普通附件 frame 后，该检查通过，现场公式上缘也完整。
