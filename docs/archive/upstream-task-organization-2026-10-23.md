# 上游任务组织、恢复与长会话优化移植（2026-10-23）

来源固定为 Tivano 2.0.0 `d31e093b356846ff538dd8ba0dc22d62598e4427`；当前分叉基线为 `c6b6028`。保留原生 OMP 所有权、独立数据域、当前 Chrome 和 Liquid Glass 范围。

## 交付范围

- 资料库逐条恢复、损坏原件／条目隔离、上次启动副本、首次独立任务格式备份、损坏轮次保存恢复和同步保存的待写轮次合并。
- 独立任务与持久目录、项目／任务分区及折叠、项目拖动、今日聚焦、分类双语图标选择、归档筛选／分组／范围固定批量删除。
- 新会话最近／固定模型与思考强度及位置策略、首次发送持久边界、选区复制与冻结引用。
- 流式解析交给完成态复用、富文本追加与选区保留、尾部字素处理、每列渐显时钟、近期回复优先预热、隐藏统计暂停、元数据缓存和异步保存后回收。

当前已有的后台 Markdown 解析、稳定保存位置算法、分段轮次、独立排版宽度缓存、MathJax 缓存和侧栏动画布局保护直接复用；条目监听改为显式增量绑定，仅条目顺序变化时重新计算保存位置，继续保留 todo 与原生上下文的持久化。没有引入上游多运行时、应用 worker 调度／MCP 代理、实时语音、CLI 外部控制、活动树或大面积玻璃。

## 优化与边界

筛选批量删除严格限制在确认时的归档 ID 集合，并重新核对仍为归档；不沿父记录扩张到筛选外子会话。缺失项目保持缺失，不能因引入 nil 归属回退为任务。任务目录查询不创建目录，首次实际提交才创建。TextKit 会把中文改用实际回退字体，因此追加判断比较 renderer 输入而非已归一化的显示存储；保留真正样式变化的完整更新。引用读取不借用剪贴板；代码／公式保留现有原文导出映射。

任务列表复用活动排序，按待处理、置顶和日期组织，并保留当前 Settle 折叠；显示、拖动同组与键盘导航共用 Core 中的排序。今日聚焦沿用旧活动视图偏好与快捷键身份，避免两个状态脱节；分钟时钟只负责失效，筛选使用当前时刻，刚更新的会话无需等下一分钟才出现。首条提交若无法保存资料库，明确失败并释放后续 admission 等待，保留草稿及可重试记录。上游 `controlWorkspace` 的修复专属于未引入的本机外部控制格式，未向 OMP GUI 添加另一套 workspace 执行器。
