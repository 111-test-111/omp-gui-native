# 主窗口设置、原生 MCP 快捷登录与完成卡片（2026-10-23）

基线 `e55d8f7`；参考 Tivano 2.0.0 `d31e093b356846ff538dd8ba0dc22d62598e4427` 的主窗口设置、MCP 目录与报告摘要设计。Dev 为 `0.1.194`／build `195`。本任务在 `codex/embedded-settings-mcp-cards` worktree 实施，保持 OMP 原生所有权和当前 Chrome／Liquid Glass 范围。

## 行为

- 设置从所有已有入口进入主窗口，支持返回、Escape 和 Command-W；保留所选页面、聊天 runtime、草稿及预览页签。覆盖时关闭聊天命令／拖放命中和可见更新，释放预览 reader／watcher，返回后恢复；不创建设置窗口。
- 复用既有、与该上游一致的 MCP 目录和已批准图标，增加分类快捷卡片、表单、文档和密钥来源链接。保存的是活动 profile 的普通原生 `mcp.json` 定义，沿用原子私有写入、冲突及目录身份保护；不运行包管理器或 MCP 工具。可选空 token 不生成空授权头，环境引用原样保留。
- OAuth 入口使用安装的 OMP npm SDK 公共导出：原生发现、`MCPOAuthFlow`、PKCE、回调、DCR、刷新材料及凭据存储。Swift 仅处理浏览器／手动回调交互及原生引用；token 和 DCR secret 不进入 GUI 偏好、JSON 或进程参数。关闭／取消／profile 变化结束这次显式操作。缺少 SDK 导出或 Bun 时说明原生 `/mcp reauth` 入口；不恢复 Tivano MCP hub、代理、Keychain 或运行时。
- 完成卡片按原生工具身份留在派出轮次；旧无身份记录按开始时间归属。整批结束、父轮次折叠或子代理归档不再清掉入口。分段轮次只出现一次，旧别名页不重复显示。连续成功仍合并，失败／停止独立；多份报告采用上游固定页头和可展开普通卡片，有界滚动，按唯一任务 ID 管理展开和解析状态。
- 归属结果依赖条目结构版本与少量子代理链接字段缓存；不观察流式正文，也不在每次布局扫描整段历史。原生调度、隔离及应用结果逻辑保持不变。
