2026-10-16；本机 OMP 18.3.2 的公开 RPC 源码为接口依据。OMP 仍独占子代理执行、模型选择、隔离、取消、steering 和结果应用；GUI 只投影事实和发出原生请求。

## 原生事实与记录身份

Hydra 保留父会话、创建工具调用、代理来源、原生会话文件、实际模型、思考级别、工作目录、隔离、应用结果及产物。不存在的字段显示“OMP 未报告”；完成执行不推断变更已应用。产物仍引用 OMP 原始文件。

原生日志可以在 session header 之前写入 title record；工作目录读取只检查本 GUI 会话存储内前 32 KiB、最多 8 条前置记录，定位 session header，不扫描完整历史或读取任意外部日志。

同一个原生代理 ID 的新启动具有新的 observation 身份，创建独立 GUI head，旧记录继续可读。旧 head 撤销停止与追加指令入口，不据此伪造其原生终态。原生会话文件、父工具调用和 observation 共同阻止旧进度、结束与异步读取进入新记录。ID 复用后，进度和结束通知至少需要匹配当前原生会话文件或父工具调用；缺少这两项身份的通知保持现状，不据此结束新任务。缺少可确认身份的旧异步投递也不归入新 head。

## 订阅粒度与补读

本版本 `set_subagent_subscription` 只有进程级的 `off`、`progress`、`events`，没有单个 head 的订阅或带会话身份的原始事件。因此 GUI 使用 `progress` 保持生命周期和摘要更新；仅详情正在显示的 head 通过 `get_subagent_messages(sessionFile, fromByte)` 补读持久化条目。主聊天和每个 Hydra 浮动面板实例分别持有可见性引用，关闭其中一个不会中断另一个。弹出动画中新旧面板短暂重叠时，也使用各自独立的引用。

`nextByte` 只在整个增量批次处理成功后推进；关闭详情取消读取。再次查看从同一文件的水位继续，处理取消时已经显示的条目不会重复。OMP 返回 `reset` 时重建该 head 的显示历史，先清理旧显示，再导入新快照。首次显示也从原生日志重建；已结束的 head 在补读后按原生终态结束显示。

原生日志中的用户消息也进入详情，包括运行途中消耗的追加指令。用户行按 observation 与持久化条目 ID 关联；首次补读或重建时使用原生日志中的任务输入，避免把 GUI 的初始任务摘要重复显示为第二条输入。

OMP 已确认接收但尚未写入用户条目的追加指令保留本地接收记录。历史重建后把这些记录放在已导入内容之后，后续原生用户条目到达时精确合并，不因重建丢失，也不重复显示。

原生 `progress` 仍实时展示近期输出和工具状态；详情中的完整消息在 OMP 持久化后显示，不声称隐藏面板接收逐 token 事件。隐藏面板没有周期性历史轮询；显示中的进度触发被合并，长批次让出主线程。

## 文件提问与 host tools

预览菜单可以把文件位置或源代码选区加入当前提问。内容保留绝对路径、起止行号、原始文本和所属 worktree；Markdown 选区使用源代码模式，以免把渲染后的 DOM 偏移误作源文件行号。添加后预览显示“已与 OMP 共享”和文件引用，并提供清除操作。仅打开、切换预览不会授权模型读取其内容。

OMP 18.3.2 的 `set_host_tools` 成功注册后，提供 `gui_read_selected_context` 与 `gui_open_file_location`：前者只返回用户明确加入的上下文，不读取任意文件；后者在当前会话或明确上下文的 worktree 内解析文件、校验符号链接实际路径并打开位置。文件来源不随稍后的聊天选择而改变。

使用真实 `host_tool_call`、`host_tool_cancel(targetId)` 与 `host_tool_result`，取消后不回传迟到结果。没有原生成功注册时不宣告工具可用。进程停止或会话替换会取消未完成请求。没有 GUI 所有的 MCP 服务、工具调度器或代理执行层。

公开接口依据：安装包的 `src/modes/rpc/rpc-types.ts`、`rpc-subagents.ts`、`host-tools.ts`、`rpc-mode.ts`。接口支持以当前进程实际成功响应为准，版本号仅作诊断信息。

## 验证

`make verify AREAS="workers"` 在 `make build` 后运行，以独立隔离目录和无模型 RPC fixture 检查 Unicode/CRLF 选区、源 worktree、原生元数据、隐藏时零历史读取、按字节补读、截断重建、ID 复用、原生 host tool 结果与取消及进程退出清理。它不启动 GUI，不修改真实 OMP profile，也不把协议回放称为真实模型或整应用验收。

后续验收为 47 项定向检查，并用 OMP 18.3.2 + K3 实跑 host tools 和隔离子代理。此版本将 host tools 挂载为 `write` 到 `xd://<工具名>`，GUI 保留原始 toolName 和 toolDevice；不把它误当文件写入。隐藏/重开后补读、实际模型、父子身份、来源和隔离工作目录均验证通过。本机 `cancel_subagent` / `steer_subagent` 返回 Unknown command，停止和追加指令控件正确保持不可用；协议回放对支持这些命令的运行时路径另有覆盖。此次异步原生结果未返回 isolation/application 布尔值，GUI 显示未知，不据工作目录推断。见 [验收记录](p3-p4-acceptance-2026-10-16.md)。
