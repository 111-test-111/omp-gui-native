# OMP 18.15.0 兼容升级与原生会话增强（2026-11-03）

Owner 要求升级 OMP，并完成 GUI 兼容适配与增强。本任务从本地 `main` 建立 `codex/omp-18-15-0` worktree；验证用固定 npm 18.15.0、Bun 1.4.4 和任务目录内的全局 npm 布局，不使用日常账号或外部模型。

## 适配与增强

- 逐文件审查 18.13.3 → 18.15.0 的 SDK 变化，重建浏览器输入／输出 SHA-256；保留精确 CEF target、后台焦点、profile Cookie／下载、证书投影及 Eval 错误归属。
- 删除 `tab-call.ts` 和 `eval/js/context-manager.ts` 补丁。新版原生 frame 调用、长等待预算及内核重启提示接替旧修复，不叠加两次提示，也不覆盖上游等待实现。
- GUI CLI 宿主和进程 worker 显式安装 OMP 公开的进程生命周期处理器；保留同步 worker inbox 优先于异步导入的启动顺序。
- 恢复会话前通过 `omp session lease --json -- <id>` 只读查询占用；明确已占用时拒绝第二次启动。未知／旧版查询不代表空闲；原生最终认领后，首次状态必须匹配原会话 ID 与规范化文件路径，阻止竞态产生的分叉被静默采用。
- Hydra 设置增加 OMP 原生逐次模型选择（关闭／仅 Eval／开启）和任务思考强度上限。使用现有 profile 冲突保护，不自动开启、不替换允许列表、不在 GUI 实现模型调度；所有新增界面文本均有 zh-Hans 翻译。
- 18.15.0 的忙时排队压缩属于原生交互界面，当前公开 RPC 的 `compact` 仍直接执行；本轮保持 GUI 的空闲压缩边界，不增加应用自有调度。

## 安装与本地集成

候选 runtime 安装于本任务 `build.noindex/omp-runtime`，完整内容摘要用于日常安装切换后的同一性核对。本记录和机器可读摘要覆盖该候选版本的验证；日常运行时的切换结果以最终交付说明为准。运行中的 GUI 须经 owner 授权正常退出后才能切换，不启动、安装或重新启动 GUI，不推送远端。

完整 GUI、真实 CEF 浏览器、外部 OAuth／模型、语音、签名安装包和性能预算不在本轮自动验证范围。独立 CEF 原型仍保留自己的固定旧版修复与历史证据，不能用来认证本次生产 SDK。
